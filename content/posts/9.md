# Conda 环境管理（激活与退出）
conda是一个环境管理软件，可以虚拟化不同的python环境，尤其是对于旧版本的python环境。用户可以自由选择python版本，不需要重复安装不同版本的python解释器。本文简单介绍如何创建、激活和退出当前环境。

<!-- more -->


创建python 版本为3.8的环境

```bash
conda create --name openmmlab python=3.8 -y
```

激活名为“openmmlab”的虚拟环境

```
conda activate openmmlab
```

退出当前环境

```
conda deactivate
```

删除名为"openmmlab"的环境, -all 参数表示删除所有的附带的安装的库

```
conda env remove -n openmmlab --all
```

为了保持磁盘空间，执行以下命令：

```
conda clean --all -y
```
这会清理删除未被任何环境使用的包（packages）。
删除下载的包的压缩文件（tarballs）。
删除一些其他的索引缓存、锁文件等。
