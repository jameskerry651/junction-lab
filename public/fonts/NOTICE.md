# Fonts used by the academic style study

All fonts are self-hosted WOFF2 subsets generated for this static reference page.
They are licensed under the SIL Open Font License 1.1; the original license files
are included next to this notice.

| File | Family | Source |
| --- | --- | --- |
| `noto-serif-sc.woff2` | Noto Serif SC (variable, wght 200–900) | https://github.com/google/fonts/tree/main/ofl/notoserifsc |
| `source-serif-4.woff2` | Source Serif 4 (variable, wght 200–900, opsz 8–60) | https://github.com/google/fonts/tree/main/ofl/sourceserif4 |
| `ibm-plex-mono-regular.woff2` | IBM Plex Mono Regular | https://github.com/google/fonts/tree/main/ofl/ibmplexmono |

The subsets contain the characters used by `design-studies/academic.html` and
`design-studies/demo-data.js`, plus common ASCII, CJK punctuation, Greek and
mathematical symbols. Regenerate them with `pyftsubset` if the sample text grows
beyond those characters.
